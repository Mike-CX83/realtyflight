The AI never gets authority — only context

Type a street address and the system pulls the real parcel boundary from county GIS (US Census geocoder + Tulsa County/INCOG). The lot becomes a proposal the operator ratifies — then the same rules judge every command. Tested against real government data, the governor made three different correct calls, unscripted:

The operator's view

Nothing flies anonymously. Approval is pinned to the exact plan hash the operator reviewed; edit one meter of altitude and the approval is void. Mid-flight the operator holds a kill switch that stops the next command, not the next step — verified by three rounds of adversarial review that probed everything from forged approvals to battery collapse mid-orbit.

Every mission — including refused and aborted ones — ends in a recorded terminal verdict. If the system can't prove a safe landing from telemetry, it says failed, never "probably fine."

A capstone project by Mike Hankins (Atlas School) — Python · PydanticAI · PX4/Gazebo · MAVSDK · FastAPI · Leaflet. Flights shown ran in the PX4 SITL simulator; the parcel data is real (US Census geocoder, Tulsa County/INCOG GIS). Code: private repo Mike-CX83/realtyflight — reviewers, ask for access.
